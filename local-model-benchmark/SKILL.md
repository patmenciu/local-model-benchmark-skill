# 本地模型测评

本 Skill 提供测评流程和评分规则，不负责启动模型。运行测评前确认本地模型接口、工具宿主和代码隔离环境可用；不具备的条件应列为未验证项。

## 准备

1. 和用户确定模型、用途、设备、运行预算与复测范围。
2. 使用 [合成题库](examples/synthetic-tasks.json)。不要读取与任务无关的本机资料，也不要将内容发送给云端模型。
3. 阅读 [测评方法](references/method.md) 和 [运行环境记录](references/runtime-metadata.md)，固定题库版本、运行合同、顺序批次及计时口径。
4. 记录实际可确认的模型标签、量化、运行后端和版本；未知字段写 `unknown`，不要根据名称推测。

## 运行与评分

- 按 [任务契约](references/task-contracts.md) 逐题运行。每次只提供当前题目、合成材料和必要的工具定义。
- 编程任务只在经过批准的隔离环境中执行。工具任务只操作题目定义的虚构状态。
- 收齐答案后，按 [评分规则](references/evaluator.md) 评分。分别记录功能、格式、运行有效性和副作用。
- D01先核对事实及来源，再做匿名内容复核；记录证据、争议与锁分状态。

## 报告

按 [结果格式](references/result-format.md) 填写记录。质量满分100，和累计模型调用时间分开报告；模型加载、首字、生成、工具执行与人工复核也分别记录，无法取得的指标写明未知。

只比较题库、运行合同、设备和批次一致的结果。未完成或运行无效的项目单独列出，不折算为完整成绩。单轮只用于初筛；模型替换或高影响用途至少增加一轮独立复测。

根据目标用途先看质量和任务完成情况，再比较用时及模块短板。没有实测的能力标为未测试。版本变化后重新确认模型身份和运行后端。此 Skill 不执行模型替换、成绩发布或答案上传。
