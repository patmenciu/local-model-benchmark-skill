# Local Model Benchmark Skill

把本地模型的「做得好不好」和「完成得快不快」分开测。


## 这是什么

这是一个**方法型 Skill**，供支持 `SKILL.md` 的 Agent 按统一流程组织本地模型测评。它包含：

- 8道任务的能力契约与全新合成题卡，覆盖推理、编程、工具、文档。
- 100分质量评分、运行有效性门禁、文档匿名复核与稳定性复测方法。
- 一份可填写的结果模板，以及不联网的结果校验、质量/用时排名工具。

**它不是一键自动评测运行器。**本包不会自动调用 Ollama、下载模型、执行模型生成的代码、模拟业务工具或自动给开放式答案打分。实际运行需要 Agent 配合已有的本地模型适配器、隔离代码执行环境与受限工具宿主；缺少条件时应报告缺口，不应编造成绩。

## 下载与安装

在本仓库的 Releases 页面下载版本 ZIP，解压后把 `local-model-benchmark/` 文件夹放入你的 Agent 的技能目录；不要把整个仓库当成技能目录。

如果使用 Codex，也可以让它在你批准的技能目录中安装这个文件夹。安装目录由你选择，本包不会修改全局配置。

调用示例：

> 使用 $local-model-benchmark，对我已经安装的两个本地模型按合成题库做测评。先检查本地运行和隔离执行条件，分别报告质量、完成用时和未验证项；不要联网、下载模型或使用我的个人文件。

## 怎么测

| 模块 | 题目 | 分值 |
|---|---|---:|
| 基础推理 | 修订分母核验、依赖推理 | 15 |
| 编程工程 | 接口实现、配置合并修复、仓库读改测 | 40 |
| 工具调用 | 只读报错恢复、确认写入与幂等核验 | 25 |
| 文档证据 | 跨材料事实、条件、状态及未知边界 | 20 |

同一设备、顺序运行、固定题库版本和运行合同；质量与速度分别排名。默认记录模型原生行为，不为了省时间统一关闭思考。建议总模型调用时限为1800秒；受时限影响的未完成运行单独列出，不当作完整低分成绩。

单次主卷用于候选筛选。高影响用途、接近的候选和模型替换，至少补充一次独立复测；不同题库、复测、诊断上限和机器的结果不得直接混分。

## 离线工具

只需已安装的 Python 3.10 或以上版本，无第三方依赖。以下命令在你选定的工作目录中运行，输入与输出路径均相对于该目录。

```bash
python3 local-model-benchmark/scripts/report.py template --output run.json
python3 local-model-benchmark/scripts/report.py validate run.json
python3 local-model-benchmark/scripts/report.py report run-a.json run-b.json --output comparison.md
```

第一条生成空白结果模板，不能直接当作已完成测评。填写真实的本地模型元数据、各题记录和人工复核后再校验；文档未锁分或任务未完成的结果不会进入正式排名。工具不会覆盖已有文件，不会读取题目以外的个人文件。

## 公开题库的边界

- 题库版本：`public-synthetic-1`。
- 此包没有附带真实实测成绩。模板中的模型标识与硬件值只是说明性占位值，不是推荐模型或性能证明。
- 题目与评分规则公开后可能被训练或针对性优化，不是保密榜单。正式选型可另建未公开的等价留出题。
- 离线单元测试证明报告工具的行为，不证明某一模型能力、Ollama兼容性、代码隔离或真实业务操作安全。
